## 修复：图片气泡只显示「🖼 图片」

### 为什么之前不行

两个原因叠加：

1. **记录里没有图片字节**。DSH 落库时把图片转成内容寻址引用：

   ```json
   { "type": "image",
     "attachment": { "attachmentId": "sha256:3e2d1a41…", "mediaType": "image/jpeg",
                     "width": 1200, "height": 2670, "bytes": 342748 } }
   ```

   内联 base64 只是**发送时**的 wire 格式，不落库。

2. **上一版只在「本机发送时」缓存字节**。所以从电脑端发的、或历史里的图片，手机本地根本没有，只能显示图标。

### 正确做法：按 `attachmentId` 向服务端取

从源码里找到了**正式接口**（之前没找到，误以为不支持）：

```
session/attachment({ sessionId, attachmentId }) -> { attachment, data: base64 }
```

实测该接口可直接取回原图（返回 457KB base64 / 342KB 二进制，1200×2670）。

现在的流程：

1. 气泡解码时先试内联 base64 → 再试本地缓存
2. 都没有 → 用 `attachmentId` 调 `session/attachment` **拉取一次**
3. 字节落盘到 `cacheDir/attachments/<sha256>`，**之后直接复用**，不再重复下载

所以**任何来源的图片都能显示**：本机发的、电脑端发的、历史记录里的。

### 附带修正

- `SessionSummary` 现在也会正确处理这类引用
- 大图按 512px 上限降采样（1200×2670 → 300×667），避免解码占内存

## 说明
