## 修复：多问题只能答第一个

ask-user 一次可以提**多个问题**（`questions: AskUserQuestionItem[]`）。旧实现有两个缺陷叠加：

1. `QuestionCard` 只渲染 `q.first` —— 界面上只有第一题
2. 答完第一题就把整个 `pendingQuestion` 置空 —— 剩下的问题**直接丢失**

现在改为：

- **逐题作答**：卡片显示当前未答的那道题，右上角显示进度（`第 2/3 题`）
- **已答题折叠显示**，并支持「撤回上一题」
- **全部答完才一次性提交**（符合协议：one item per question of the call）
- 提交失败时**把提问放回去**，不用重答一遍

## 改用官方 RPC 提交答案

之前是把答案拼成文本走 `session/prompt(steer)` —— 能用但不符合协议。现在改为正式接口：

```
userQuestions/answer(agentId, callId, answer: { answers: [{ id, selected: string[] }] })
```

顺带修正了一个**早先的错误结论**：我曾判断「ask-user 无法通过 RPC 回答」，实际是有的，只是当时没找到。

## 新增：多选问题支持

协议里 `AskUserQuestionItem.multiSelect` 表示多选题，之前完全没处理（点了只记一个）。现在：

- `multiSelect: true` 时显示复选框，可勾选多个
- 底部出现「提交本题（可多选）」按钮
- 答案按 `selected: string[]` 提交

同时补上了 `detail`（问题的补充说明）的展示。

## 已知限制

- **`callId` 缺失时会走兜底**：若提问帧里拿不到 `callId`，仍回退为文本 steer（不至于卡死，但格式不标准）
- 本版本**未做真机回归**：协议层已用真实 API 验证参数正确（`userQuestions/answer` 返回 `ok:true`），但多题 UI 的交互未实测

## 系统要求

- Android 8.0+（minSdk 26）
- 手机能访问到 dsh-pocket —— 同一局域网，或 dsh-pocket 开启外网模式
