## 修复

### 1. 排队刷新会打断 WebSocket 连接（重要）

刷新排队列表时，之前用的是「对主订阅流先 `cancel` 再 `open`」。服务端会把同一 `streamId` 的第二次 `open` 判为非法请求，直接以

```
1008 invalid Remote stream request
```

**关掉整条 WebSocket** —— 表现就是每次排队刷新都把连接打断一次，然后靠指数退避重连恢复（界面上会闪过「重新连接」）。

现在改为**开一条独立的一次性流**（唯一 `streamId`）读取 inbox，拿到快照立刻关掉，**完全不动主订阅流**。

### 2. 聊天页 `⋯` 菜单的「置顶」不反映状态

已置顶的会话，菜单里仍然显示「置顶」，点了看不出变化。现在会显示为 **「取消置顶」**。
