# dsh_mobile v0.1.0

DSH 的原生 Android 客户端首个版本。

## 下载

- **`dsh_mobile-0.1.0-release.apk`** (2.32 MB)

> 需要配合电脑侧的 **[dsh-pocket](https://github.com/shaobeichen/dsh-pocket)** 使用 —— 它提供局域网中转、配对二维码与 PIN。

### 安装

1. 把 APK 传到手机并安装（首次需允许「安装未知来源应用」）
2. 电脑上启动 dsh-pocket，显示二维码与 PIN
3. 打开 App → **扫码连接**（或手动输入地址 + PIN）

**校验**（可选）：APK SHA-256
```
8A844B50DE9BA7C638D96A119DA815781EF0E939054031A7EF84649ECBCDC567
```

## 功能

- **连接**：扫码配对 / 手动 PIN；多服务器切换；断线指数退避重连 + 快照重同步；DSH 重启后自动重登
- **会话**：按工作区分组（可折叠）、置顶、归档、搜索、重命名、派生新会话、按工作区新建
- **对话**：token 级流式输出、思维链折叠、工具调用卡片（参数+结果）、Markdown、历史分页、中断回合
- **排队 / 插队**：任务运行中发送自动排队（悬浮胶囊），支持编辑 / 立刻发送 / 取消
- **附件**：图片内联发送 + 气泡内缩略图；文档（PDF/Office/文本/代码）上传后可用系统 App 打开
- **语音**：语音识别转文字；语音态切换为波形 + 停止 + 发送
- **界面**：沉浸式无标题头部、单行输入胶囊、深浅双主题 + 4 种强调色

## 已知限制

| 限制 | 说明 |
|---|---|
| ask-user 提问无法回答 | 上游 RPC 没有回答入口 |
| 历史文档附件无法重新下载 | 服务端不提供附件回取；只有本机刚发送的文档能打开 |
| `session/search` 在本部署被禁用 | 已改为本地过滤 |

## 系统要求

- Android 8.0+（minSdk 26）
- 手机与电脑在同一局域网
