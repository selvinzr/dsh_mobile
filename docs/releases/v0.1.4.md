## 修复

### 输入框 placeholder 用会话标题，容易被误认为已输入内容

之前空闲时输入框里显示**会话标题**，看起来像草稿里已经有字了，容易让人以为自己输入过什么、或者误删。

现在改为固定短提示：

```
询问 DSH
```

（与 ChatGPT 的「询问 ChatGPT」同一思路。）会话标题仍在侧边栏显示，不丢信息。
