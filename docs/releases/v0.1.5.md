## 修复：「其他」里塞满了子 agent 会话

在真实数据上实测：**1217 个会话里，1056 个是子 agent**（占 87%），「其他」分组一度有 **1091 条**。其中单个父会话就派生了 **681 个子任务** —— 列表完全没法用。

### 原因

DSH 的 `session/list` 里，子 agent 会话是**独立条目**，只是带了 `parentSessionId`。之前的实现把它们当成普通会话直接列出来了。

### 改法

| 项 | 行为 |
|---|---|
| **识别** | 用 `parentSessionId`（以及 `projections.values.subagent`）判定子 agent |
| **「其他」** | **排除所有子 agent**，只保留没有归属项目的顶层会话 |
| **子任务呈现** | 父会话下方显示一行 **「子任务 N」**（带分支图标），**默认收起** |
| **展开后** | 逐个列出子任务：label/标题 + 相对时间 + 运行中转圈；点击可直接进入该子会话 |
| **展开状态** | 按父会话 id 记忆，滚动不会丢 |

效果：那条有 681 个子任务的会话，现在在列表里只多 **1 行**。

## 说明
